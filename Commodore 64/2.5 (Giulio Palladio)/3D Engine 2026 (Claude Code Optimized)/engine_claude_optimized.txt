`oo%` is an array of integers (±32767), so the average was truncated.

would end up with the same key, leaving them in a random order. The multiplier `mk` uses the entire range:

Calculating `mk` at startup (lines 130, 131, 140)

Rotation does not change a vertex's distance from the origin; therefore, |z| ≤ sqrt(x²+y²+z²) for any angle.
`mk` is calculated only once while reading the vertices, by dividing 30,000 by the maximum distance.
The maximum is calculated using `rm=rm-(r>rm)*(r-rm)` instead of `if r>rm then rm=r`, because in BASIC 2.0, a false `if` condition would cause the `next` statement on the same line to be skipped.
